# SEO Checklist

Use this checklist for public, search-indexable pages.

## Metadata

- [ ] Page title is unique and descriptive.
- [ ] Meta description is useful and relevant.
- [ ] Canonical URL is correct where required.
- [ ] Open Graph metadata is appropriate.
- [ ] Social preview image is appropriate.

## Content Structure

- [ ] One appropriate primary heading exists.
- [ ] Heading hierarchy is logical.
- [ ] Important content is present in crawlable HTML.
- [ ] Content clearly matches search intent.
- [ ] Copy is useful rather than keyword-stuffed.

## URLs and Navigation

- [ ] URL is clean and stable.
- [ ] Internal links are useful.
- [ ] Anchor text describes the destination.
- [ ] Important pages are reachable through internal navigation.

## Images

- [ ] Images are optimized.
- [ ] Informative images have meaningful alt text.
- [ ] Decorative images do not add unnecessary accessibility noise.
- [ ] Images have reserved dimensions where appropriate to reduce layout shift.

## Structured Data

- [ ] Structured data is used only when applicable.
- [ ] Structured data accurately represents visible page content.
- [ ] No misleading or fabricated structured data is added.

## Technical SEO

- [ ] Robots directives are intentional.
- [ ] Sitemap strategy is correct.
- [ ] Canonical handling is correct.
- [ ] Duplicate URL handling is considered.
- [ ] Client-only rendering does not hide important content unnecessarily.

## Performance

- [ ] Critical content loads quickly.
- [ ] Images and fonts are optimized.
- [ ] JavaScript is not unnecessarily required for primary content.
- [ ] Layout shifts are minimized.

## Accessibility Relationship

SEO and accessibility should reinforce each other.

- [ ] Semantic HTML is used.
- [ ] Links are descriptive.
- [ ] Headings are meaningful.
- [ ] Images have appropriate alternatives.
- [ ] Important content is understandable without visual styling.

## Final Questions

- [ ] Is the page genuinely useful to a visitor?
- [ ] Is the page SEO-friendly?
- [ ] Is important content crawlable?
- [ ] Is the content natural rather than keyword-stuffed?
- [ ] Is the page fast?
- [ ] Is accessibility handled?
- [ ] Does the implementation remain visually premium?
- [ ] Is this something I'd be proud to ship?
