# Marketing Prompt

Act as a senior product designer, UX writer, SEO specialist, and frontend engineer.

Create a marketing page that combines strong visual design, clear messaging, conversion intent, accessibility, SEO, and performance.

## Content

Identify:

- Audience
- User problem
- Product value
- Differentiators
- Proof
- Primary conversion action

Write concise, specific copy. Avoid generic claims and keyword stuffing.

## Design

Use a strong hierarchy, premium typography, deliberate whitespace, meaningful visuals, restrained effects, and consistent components.

Do not make every section visually identical or decorate every surface.

## Conversion

Make the next action obvious and reduce uncertainty through useful proof, explanations, and accurate CTAs.

## SEO

Implement appropriate metadata, headings, crawlable content, internal links, optimized images, canonical handling, and structured data only where applicable.

## Performance

Keep initial JavaScript small, optimize images/fonts, lazy-load non-critical media, and avoid heavy animation or third-party scripts unless justified.

## Accessibility

Use semantic HTML, keyboard-accessible controls, visible focus, sufficient contrast, meaningful image alternatives, and reduced-motion support.

## Final quality gate

- Is this visually premium?
- Can spacing be improved?
- Can typography be improved?
- Is the UI consistent?
- Is the component reusable?
- Is the code optimized?
- Will Lighthouse score well?
- Is the page SEO-friendly?
- Is accessibility handled?
- Is this something I'd be proud to ship?
