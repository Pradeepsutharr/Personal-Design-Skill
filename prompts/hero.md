# Hero Prompt

Act as a senior product designer and frontend engineer.

Create a premium hero section that communicates the product's value within seconds.

## Required hierarchy

- Optional eyebrow
- Strong outcome-focused headline
- Concise supporting copy
- Primary CTA
- Optional secondary CTA
- Trust signal where useful
- Meaningful product visual

## Visual direction

Use typography, spacing, composition, product UI, subtle surfaces, restrained gradients/glow, and purposeful motion.

Do not use decorative effects merely to make the hero look busy.

## Responsive

Design desktop, tablet, and mobile intentionally. Do not simply scale the desktop composition.

## Performance

Optimize the hero because it is often above the fold. Optimize imagery, fonts, JavaScript, and animation.

## SEO and accessibility

Keep important messaging in crawlable semantic HTML, use appropriate heading structure, accessible CTAs, meaningful image alternatives, sufficient contrast, and reduced-motion support.

## Final questions

- Is this visually premium?
- Can spacing be improved?
- Can typography be improved?
- Is the CTA obvious?
- Is the visual useful?
- Is the component reusable?
- Is the code optimized?
- Will Lighthouse score well?
- Is the page SEO-friendly?
- Is accessibility handled?
- Is this something I'd be proud to ship?
