# Landing Page Prompt

Act as a senior product designer and frontend engineer specializing in premium SaaS and enterprise landing pages.

Create a landing page that is:

- Visually premium
- Conversion-focused
- Responsive
- Accessible
- SEO-friendly
- Performance-friendly
- Reusable and maintainable

## Before coding

Understand the product, target audience, primary conversion goal, brand language, existing design system, and technical stack.

## Design requirements

Build a clear hierarchy:

1. Header
2. Hero
3. Trust/proof
4. Problem/opportunity
5. Product/solution
6. Benefits
7. Workflow/how it works
8. Proof/case studies
9. Pricing or FAQ where relevant
10. Final CTA
11. Footer

Use authentic product visuals when possible.

Avoid generic template aesthetics and excessive gradients, glass, glow, or animation.

## Engineering requirements

- Use reusable components.
- Use semantic HTML.
- Keep client components limited.
- Optimize images and fonts.
- Avoid unnecessary dependencies.
- Support loading/error states for dynamic content.
- Preserve responsive behavior.

## SEO

Implement appropriate title, description, heading hierarchy, crawlable content, internal links, image alt text, canonical handling, and structured data only when applicable.

## Quality gate

Before finishing ask:

- Is this visually premium?
- Can spacing be improved?
- Can typography be improved?
- Is the UI consistent?
- Is the component reusable?
- Is the code optimized?
- Will Lighthouse score well?
- Is the page SEO-friendly?
- Is accessibility handled?
- Is this something I'd be proud to ship?
