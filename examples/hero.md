# Hero Section Example

Use this example when designing a high-impact hero for a SaaS, product, service, or marketing page.

## Goal

Communicate the product's value quickly while creating a strong first visual impression.

## Recommended Structure

```text
Hero
├── Eyebrow / category (optional)
├── Primary headline
├── Supporting value proposition
├── Primary CTA
├── Secondary CTA (optional)
├── Trust signal (optional)
└── Product visual / illustration
```

## Content Hierarchy

The hero should answer:

1. What is this?
2. Who is it for?
3. Why does it matter?
4. What should I do next?

Do not overload the hero with every product feature.

## Headline

Prefer outcome-focused headlines.

Weak:

`The future of business software`

Stronger:

`Run your marina operations from one intelligent platform`

The exact wording must match the actual product and audience.

## Supporting Copy

Keep supporting text concise and useful.

It can explain:

- The problem solved
- The primary outcome
- The target customer
- A meaningful differentiator

Avoid repeating the headline.

## CTA

Use one clearly dominant primary CTA.

Examples:

- `Start free`
- `Book a demo`
- `Create account`
- `Explore platform`

A secondary CTA can be used when it serves a distinct lower-commitment path.

## Product Visual

Prefer meaningful product UI over generic decorative artwork when the product itself is the value proposition.

Good hero visuals can show:

- Dashboard
- Workflow
- Map
- Analytics
- Product interface
- Realistic device mockup

Use realistic content rather than meaningless placeholder blocks.

## Premium Visual Direction

Use visual hierarchy rather than excessive effects.

Possible ingredients:

- Strong typography
- Large but controlled display type
- Subtle gradient atmosphere
- Fine borders
- Layered surfaces
- Restrained glow
- Product UI depth
- Subtle motion

Do not use every effect simultaneously.

## Layout

A common desktop pattern is:

```text
Text / CTA       Product Visual

     supporting trust signal
```

A centered hero can work when the visual is secondary or when the brand calls for a strong editorial composition.

## Responsive Behavior

### Desktop

Give the headline enough width to create a strong shape without becoming a paragraph.

### Tablet

Reduce visual complexity and adjust the text/visual ratio.

### Mobile

Stack content intentionally:

```text
Eyebrow
Headline
Description
CTA
Trust
Visual
```

Do not simply shrink the desktop layout.

## Performance

Hero content is often above the fold, so optimize it carefully.

- Optimize the main image.
- Use responsive image sizing.
- Avoid unnecessary video backgrounds.
- Avoid heavy client-side animation.
- Keep critical text server-renderable where appropriate.
- Avoid loading large decorative assets before important content.

## SEO

For public pages:

- Use one appropriate primary heading.
- Keep the important value proposition in crawlable HTML.
- Use descriptive image alt text when the image conveys information.
- Do not place critical SEO content only inside a canvas or image.
- Provide appropriate metadata at the page level.

## Accessibility

Ensure:

- Semantic heading structure
- Keyboard-accessible CTAs
- Visible focus states
- Sufficient contrast
- Meaningful image descriptions
- Reduced-motion support

## Review Questions

- Is the value proposition obvious immediately?
- Is this visually premium?
- Can spacing be improved?
- Can typography be improved?
- Is the CTA obvious?
- Does the visual communicate something useful?
- Is the UI consistent?
- Is the component reusable?
- Is the code optimized?
- Will Lighthouse score well?
- Is the page SEO-friendly?
- Is accessibility handled?
- Does the hero work beautifully on mobile?
- Is this something I'd be proud to ship?
